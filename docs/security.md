# Security and Disclosure Policy

This repository contains documentation and sanitized interface screenshots only.

## Not published

- Production PHP, JavaScript, SQL schema or deployment scripts
- Passwords, tokens, private keys, certificates or fiscal credentials
- Customer or employee records, orders, operational identifiers or financial figures
- Internal network addresses, endpoints, database configuration or infrastructure topology

Screenshots are copies with selected regions permanently replaced with solid-color pixels. The source screenshots remain outside the repository. Review every image again before public upload, including small text and contextual identifiers. The screenshots are genuine interface captures with redacted regions, not proof of completed integrations or external certification.

For security concerns, contact the repository owner privately.
