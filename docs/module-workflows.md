# Module Workflows

## Operational overview

The dashboard surfaces orders awaiting action, preparation activity, occupied tables and delivery-related items. Counts and identifiers in the public screenshot are redacted or should be treated as illustrative to the captured environment.

## Client configuration

The interface groups company data, fiscal configuration, digital certificates, delivery integration, optional intelligence capabilities and system diagnostics. The visible screen reports integration states; it does not prove successful connectivity.

## Finance

The financial interface presents cash position, income, expenses, receivables, reports and related navigation. Sensitive amounts are not published.

## Fiscal monitoring

The fiscal module includes monitoring/error-audit views and navigation for related fiscal processes. The screenshot alone does not establish external authorization, issuance, cancellation or regulatory readiness.
